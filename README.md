## The entry

A single hilarious line (under 200 characters) that lands entirely on its own: a driver asks the GPS for the scenic route, and the GPS answers with a guided tour of their emotional damage — past the ex's house, past the therapist's office, and finally a billboard that just says "RUN." Misdirection, escalation, and one absurdly specific final image, with no wasted words.

## How to run

Requires Node 22.18 or later (the program is plain TypeScript with no dependencies):

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and self-checks that the text is a single line of 1 to 200 characters.
